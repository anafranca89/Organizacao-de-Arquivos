# Manipulação de arquivos utilizando índices Árvore B
O seguinte trabalho tem como objetivo implementar um sistema de manipulação de arquivos, desde a leitura de dados obtidos por um arquivo .csv e manipulação dos dados em arquivos binários. 

## Branch Main
A branch main contém a parte 1 do trabalho, com as funções 1 a 6, que lidam apenas com manipulação do arquivo de dados. 
Está atualizada usando structs e funções auxiliares para modularização, em relação a branch Melhorias...


## Branch ArvB
A branch arvb contém os arquivos do projeto parte 2, onde estão implementadas as funções sem o uso da lógica de árvore B, da parte 1, e as novas funções com o uso da lógica de índices - funções 7, 8, 9, 10.
